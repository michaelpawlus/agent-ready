agent-ready badge

Hosted score endpoint for agent-ready. Drop a shield in any repo's README and a fast subset of public signals decides the grade.

Use it

![agent-ready](https://agent-ready-badge.vercel.app/badge/OWNER/REPO.svg)

JSON scorecard

curl https://agent-ready-badge.vercel.app/badge/OWNER/REPO.json

What it scores

The hosted endpoint cannot clone arbitrary repos, so it computes a public-signals-v1 subset (eight binary signals from the GitHub Contents API and the PyPI JSON API). Run agent-ready score locally for the full ~30-check rubric.

  • README mentions --json
  • README is substantial (≥ 1500 chars)
  • CHANGELOG.md present
  • LICENSE present
  • CI workflow in .github/workflows/
  • [project.scripts] in pyproject.toml
  • PyPI release within the last 180 days
  • py.typed marker present
